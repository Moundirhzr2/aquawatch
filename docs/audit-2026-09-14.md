## Fixes

- **Malformed write-token header:** a non-ASCII header reached `secrets.compare_digest` and raised `TypeError`, causing a server error. The middleware now rejects it with HTTP 403 before comparison. A regression test reproduced the failure before the fix and verifies rejection without an import. The running local API was relaunched and checked with the malformed header; its overview, cases and import ledger were preserved.
- **Test dependency advisory:** pytest 8.4.2 was affected by [CVE-2025-71176](https://github.com/advisories/GHSA-6w46-j5rx-g56g), involving insecure temporary-directory handling on Unix. Updated the development requirement and lockfile to pytest 9.0.3, the [patched release](https://github.com/pytest-dev/pytest/releases/tag/9.0.3), and reran both database test suites. Pytest is a development dependency, not part of the application runtime image.
